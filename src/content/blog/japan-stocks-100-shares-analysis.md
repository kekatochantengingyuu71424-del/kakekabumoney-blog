## 数えてみたら、思っていたより露骨だった

私は日本の高配当株を、気になった銘柄から1株ずつ買い集めてきました。今回、**NISA成長投資枠で持っている日本株97銘柄**について、含み損益を一度きちんと集計してみました。

そうしたら、自分でも予想していなかった傾向が、かなりはっきり出ました。

**100株まとめて買った銘柄だけ、見事に負けていました。**

それ以外の買い方——1株だけ、数株だけ——は、どれも平均でプラスです。この差があまりにきれいに出たので、記事にします。

## 先に、集計の前提を書いておきます

公開するにあたって、**金額は一切出しません**。

- 取得金額、時価評価額、資産の合計 → **すべて非公開**
- 公開するのは**銘柄名と騰落率**だけ（何%のプラスマイナスか）
- 保有株数は、個別には出さず**区分**でまとめます

騰落率は「いくら投じたか」とは無関係な数字なので、これなら資産規模は分かりません。それでいて、今回いちばん書きたい傾向は伝わります。

なお、今回集計したのは**NISA成長投資枠にある日本株**で、特定口座の分は含めていません。

## 全体の成績：勝率66%

まず全体です。

| | 銘柄数 |
|---|---|
| 含み益（プラス） | **64銘柄** |
| 含み損（マイナス） | **33銘柄** |
| 合計 | **97銘柄** |

勝率にすると**約66**%。3銘柄に2銘柄はプラス、という状態です。

相場全体が良かった時期の恩恵も大きいので、これを自分の実力だとは思っていません。ただ、**1株ずつ買い集めるやり方でも、ちゃんと勝てている**ことは確認できました。

## 本題：保有株数で分けると景色が変わる

ここからが本題です。**保有している株数**で銘柄を分類して、それぞれの平均騰落率と勝率を出しました。

| 保有株数の区分 | 銘柄数 | 平均騰落率 | 勝率 |
|---|---|---|---|
| 1株未満（端株） | 17銘柄 | **+13.5%** | 71% |
| 1株ちょうど | 33銘柄 | **+21.5%** | 76% |
| 2〜9株 | 22銘柄 | **+27.8%** | 73% |
| 10〜99株 | 16銘柄 | **+11.6%** | 56% |
| **100株以上** | **9銘柄** | **-14.0%** | **22%** |

**100株以上の行だけ、符号が逆**です。

平均で**マイナス14**%、勝率は**22**%。9銘柄のうちプラスは2銘柄しかありません。他の区分はすべて平均プラス、勝率も7割前後なのに、ここだけ完全に裏返っています。

さらに言うと、**含み損ワースト4銘柄は、すべて100株保有**でした。

## 100株以上の9銘柄、全部さらします

隠しても仕方ないので、全部出します。騰落率の悪い順です。

| 銘柄 | 騰落率 |
|---|---|
| enish | **-51.72%** |
| 北浜キャピタルパートナー | **-40.00%** |
| WIZE | **-26.47%** |
| 楽天グループ | **-25.94%** |
| 北の達人コーポレーション | -6.95% |
| 野村不動産ホールディングス | -5.20% |

| SBIグローバルアセットマネジメント | +5.20% |
| UTグループ | +27.23% |

**9銘柄中7銘柄がマイナス**。しかも上位4つは2桁マイナスです。

## なぜ、こうなったのか

自分なりに3つ考えました。都合の悪い解釈も含めて書きます。

### ① 実は「株数」ではなく「銘柄の質」の問題

これが最も正直な説明だと思います。

**100株買えたのは、その株が安かったからです。**

私が100株持っている銘柄の取得単価を見ると、**100円を切るものが複数あります**。一方、1株しか持っていない銘柄には、日本たばこ産業・信越化学・武田薬品・三菱総合研究所のように**1株数千円の大型株**が並びます。

つまり、こういう構図でした。

- **単価の高い優良株** → 1株しか買えない → 結果プラス
- **単価の安い小型株** → 100株買える → 結果マイナス

「100株買ったから負けた」のではなく、**負けやすい銘柄が、たまたま100株買える値段だった**わけです。因果が逆かもしれない、というのは認めておかなければいけません。

とはいえ、**結果として同じこと**でもあります。「安いからたくさん買える」という発想で銘柄を選ぶと、こうなりやすい。

### ② 100株買うときは、自信があった

もうひとつ、心当たりがあります。

1株だけ買うときは「**とりあえず様子を見よう**」という気持ちです。ところが100株まとめて買うときは、たいてい「**これは行ける**」と思っています。

その自信が、当たっていない。

思い返すと、100株買った銘柄には**期待で買ったもの**が多いです。優待が魅力的だった、業績が伸びると思った、安いから戻るはずだと思った。**根拠が薄い期待ほど、大きく張ってしまう**傾向があったのかもしれません。

### ③ 1株なら、失敗が傷にならない

逆側から見ると、こうも言えます。

1株しか持っていない銘柄が仮に半値になっても、**金額としてはほとんど痛くありません**。だから冷静でいられるし、慌てて売らずに済む。持ち続けているうちに戻ったものもあります。

**「失敗しても傷が浅い買い方」が、結果的に成績を守ってくれた**という面は確実にあると思います。

## 楽天グループが含み損である件

触れないわけにいかないので、正直に書きます。

このブログで私は、**楽天グループの株主優待**を何度も紹介してきました。100株保有で楽天モバイルのSIMが1年間無料になる優待で、私の「本命の優待」だと書いてきました。

その楽天グループが、**マイナス25.94**%です。

ただ、これについては後悔していません。理由は、**この銘柄を優待目的で買っているから**です。通信費が年間1万円以上浮く状態が続いているので、株価が下がっていても、**買った目的は果たせています**。

逆に言えば、**優待が廃止されたら持つ理由がなくなる**銘柄でもあります。そうなったときに惰性で持ち続けないように、という自戒も込めて書いておきます。

## ちなみに、伸びている銘柄も出しておきます

負けの話ばかりでは片手落ちなので、含み益の上位も出します。すべて**10株以下**の保有です。

| 銘柄 | 騰落率 |
|---|---|
| 日清紡ホールディングス | **+193.02%** |
| グッドコムアセット | +86.14% |
| 日本たばこ産業 | +76.95% |
| 東計電算 | +76.20% |

トップの日清紡は**3倍近く**になっています。ただし保有は数株なので、**資産へのインパクトはごくわずか**です。

ここが分散投資の割り切りどころで、**大当たりしても人生は変わりません**。その代わり、大外ししても沈みません。私はこの性質を承知のうえで、この買い方を選んでいます。

## この結果を、どう受け止めるか

自分への教訓として、3つに整理しました。

### ① 「安いからたくさん買う」はやめる

100株組の負けは、**単価の安さで株数を決めていた**ことが原因だと思っています。

株価が安いことと、その会社が割安であることは、まったく別の話です。**100株買えるかどうかは、銘柄選びの基準にしてはいけません**。

### ② 自信があるときほど、小さく買う

これは逆説的ですが、データはそう言っています。

「これは行ける」と思った銘柄ほど外している以上、**自信の大きさと投資額を連動させない**ほうが安全です。むしろ自信があるときこそ、まず1株から始めたほうがいい。

### ③ ただし、これは9銘柄の話

最後に、自分で自分にブレーキをかけておきます。

**100株以上の区分は、たった9銘柄しかありません。** サンプルとしては明らかに小さく、たまたまこの9銘柄が悪かっただけ、という可能性は十分あります。

また、今回の数字は**ある時点のスナップショット**です。相場が変われば順位も入れ替わりますし、**配当を受け取った分は含まれていません**。高配当株は配当込みで評価すべきなので、この表だけで良し悪しは決まりません。

それでも、**自分の傾向として見ておく価値はある**と思っています。
