## 配当6位の銘柄は、含み損がいちばん重い

配当上位の銘柄を順に点検しています。きっかけは、**配当1位のアサンテが配当性向220%だった**ことでした。

📖 その話 → [私の配当1位はシロアリの会社だった](/blog/asante-dividend/)

今回は**配当6位のニホンフラッシュ**（7820）です。

この銘柄は、私の配当上位の中で**評価損益がいちばん悪い**部類に入ります。配当は稼いでいるのに、株価では負けている。その理由を調べました。

## ニホンフラッシュとは

**マンション向けの内装ドア**を作っている会社です。

室内のドアや収納扉、間仕切りといった建具を、マンションの開発事業者に供給しています。徳島県に本社があり、**国内の分譲マンション向けでは高いシェア**を持つとされています。

そしてもうひとつ特徴があります。**中国に大きな事業展開をしている**ことです。ここが後で効いてきます。

## 数字を見ます

| 項目 | ニホンフラッシュ |
|---|---|
| 私の配当に占める割合 | **4.12%**（6位） |
| 評価損益率 | **マイナス10.26**% |
| 年間配当（2027年3月期予想） | **36円** |
| **配当性向** | **57.9**%（2026年3月期） |

**配当性向57.9%は健全な水準**です。アサンテの220%とは全く違います。日本企業の平均（35%前後）より高めですが、「やや高め」の範囲に収まっています。

📖 配当性向の目安 → [配当性向の平均は何%？目安・危険ラインと、配当利回りとの違い](/blog/dividend-payout-ratio/)

つまり**配当そのものに無理はありません**。では、なぜ株価は下がっているのか。

## 配当は4年間、据え置きです

まず気づいたのがこれです。

| 決算期 | 年間配当 |
|---|---|
| 2022年3月期 | 32円 |
| 2023年3月期 | **36円** |
| 2024年3月期 | 36円 |
| 2025年3月期 | 36円 |
| 2026年3月期 | 36円 |
| 2027年3月期（予想） | **36円** |

2023年3月期に36円へ増配してから、**ずっと据え置き**です。減配はしていませんが、増配もしていません。

減らさないのは評価できます。ただ、**増配を期待して持つ銘柄ではない**ということははっきりしました。

📖 増配の価値について → [増配の価値は「買値」に出る](/blog/dividend-growth-stocks/)

## 弱点は中国事業

業績を見ると、**利益はむしろ回復しています**。

2026年3月期は売上こそ微減でしたが、**営業利益は前期比で大きく伸びました**。数字だけ見れば悪くありません。

にもかかわらず株価が振るわないのは、**中国事業の低迷**が意識されているからだと思われます。決算の説明でも、国内の賃貸住宅向けは好調な一方、**中国事業が足を引っ張っている**という趣旨の記載が見られます。

中国の不動産市況は長く低迷しており、**マンション向け建材を作る会社にとっては直撃する環境**です。国内で好調でも、中国の重しが消えない限り、評価されにくい状況が続く可能性があります。

これは一企業の努力でどうにかなる話ではありません。**外部環境のリスク**です。

## どう判断するか

私は減配を3つに分けて考えています。

| 種類 | 対応 |
|---|---|
| 見かけの減配（株式分割） | 何もしない |
| 一時的な減配（業績の波） | 様子を見る |
| 構造的な減配・無配 | 売却を検討 |

📖 → [減配されたらどうする？180銘柄持つ私が売った銘柄と、売らなかった銘柄](/blog/dividend-cut-what-to-do/)

ニホンフラッシュは、**まだ減配していません**。配当性向にも余裕があります。つまり**この枠組みで言えば、まだ何も起きていない**状態です。

含み損が10%を超えているのは事実ですが、**株価が下がっていること自体は売る理由になりません**。私は「株価が下がったから売る」という判断をしないと決めています。

📖 売る基準について → [高配当株に売り時はあるか](/blog/when-to-sell-dividend-stocks/)

ただし、注意して見るべき点は明確になりました。

**中国事業が改善に向かうかどうか。**

ここが好転しないまま国内の好調も息切れすれば、配当性向57.9%という余裕も削られていきます。そうなったときが、判断のタイミングです。

## 点検の結論：持ち続けるが、見る場所は決まった

結論としては**持ち続けます**。

- **配当性向は健全**で、配当を出す体力がある
- **減配していない**
- 利益そのものは**回復傾向**

一方で、**増配を期待する銘柄ではない**ことと、**中国事業という外部要因を抱えている**ことがはっきりしました。

私は180銘柄を持っていて、全部の決算を追うのは現実的に無理です。ただ、**配当上位の銘柄だけは見る**と決めています。この銘柄については、**中国事業の動向**という具体的な着眼点が得られました。

点検の目的は、売るか持つかを決めることだけではありません。**次にどこを見ればいいかをはっきりさせること**でもあると思っています。
